# 文档导航

> 项目根目录只保留一个入口 `README.md`；这里按「先跑 → 再看结构 → 再深挖」组织文档。

## 推荐阅读顺序

| 顺序 | 文档 | 适合什么时候看 |
|---|---|---|
| 1 | [`../README.md`](../README.md) | 第一次打开仓库：项目做什么、怎么跑、接口与配置 |
| 2 | [`architecture.md`](architecture.md) | 想知道目录边界、一次请求经过哪些包、改功能看哪里 |
| 3 | `docs/local/项目学习指南.md` | 想用 3 天快速理解 / 复述项目（本地文档，不随仓库分发） |
| 4 | `docs/local/项目知识文档.md` | 深挖设计取舍、实测口径、面试问答（本地文档，不随仓库分发） |
| 5 | `docs/local/数据库设计说明.md` | 表结构、索引、数据量与设计理由（本地文档，不随仓库分发） |
| 6 | [`重构计划书.md`](重构计划书.md) | 想知道已经做过什么、哪些明确后置 |

## 文档地图

```text
docs/
├─ README.md                本文件：阅读入口
├─ architecture.md          代码结构 / 请求流 / 改动地图
├─ 重构计划书.md            P0/P1/P2 记录与取舍
├─ images/                   README 使用的截图
└─ local/                    本地深度文档（gitignored，不随仓库分发）
   ├─ 项目学习指南.md
   ├─ 项目知识文档.md
   └─ 数据库设计说明.md
```

## 约定

- **根目录 README 是唯一总入口**，不再在根目录堆多份长文档。
- 结构性问题写进 `architecture.md`；设计取舍写进本地深度文档；历史任务写进 `重构计划书.md`。
- `docs/local/` 不提交到仓库，避免把个人面试笔记/大体量笔记混进项目历史。
- 图片只放 `docs/images/`；截图引用使用相对路径，保证 GitHub 上可直接预览。
